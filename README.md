## Português

**Informações do sistema Linux diretamente no terminal.**

O InformaSam é um projeto desenvolvido em Python, inspirado no Neofetch, com o objetivo de exibir informações do sistema operacional e do hardware de maneira organizada e visualmente agradável.

O projeto também representa uma iniciativa de aprendizado em Python, Linux e desenvolvimento de software.

### Objetivos

- Exibir informações do sistema operacional.
- Identificar processador e memória RAM.
- Exibir informações do kernel e ambiente gráfico.
- Apresentar um logotipo ASCII da distribuição Linux.
- Organizar as informações com cores e alinhamento no terminal.

### Tecnologias

- Python 3
- Linux
- Git
- GitHub

### Desenvolvimento

O InformaSam está em desenvolvimento. Novos recursos serão implementados gradualmente.

## English

**Linux system information directly in the terminal.**

InformaSam is a Python project inspired by Neofetch. Its goal is to display operating system and hardware information in an organized and visually appealing way.

The project is also a learning initiative focused on Python, Linux, and software development.

### Goals

- Display operating system information.
- Identify the processor and RAM.
- Display kernel and desktop environment information.
- Present an ASCII logo of the Linux distribution.
- Organize information with colors and alignment in the terminal.

### Technologies

- Python 3
- Linux
- Git
- GitHub

### Development

InformaSam is currently under development. New features will be implemented gradually.
